# Synapse — что есть сейчас, простыми словами

Состояние на 25.09.2026 (ветка `main`, коммит `839a8b1`). Подробные цифры и методика — в
[`README.md`](README.md), история создания — в [`dialog/dialog.md`](dialog/dialog.md).

---

## В двух словах

**Synapse** — это искусственный «мозг», собранный по образцу отделов живого мозга (кора, гиппокамп,
мозжечок, базальные ганглии, миндалина и т. д.). Каждый отдел — отдельный модуль со своей работой,
как микросервис. Модули общаются через «спайки» (активные нейроны).

Из него сделаны две вещи:

1. **Языковой мозг** — предсказывает и пишет текст. На своей задаче он обгоняет маленький
   трансформер при равном времени обучения, и всё это на одном ядре процессора.
2. **«Синапс» — житель Minecraft.** Бот с телом в игре, чувствами, памятью, эмоциями и
   собственными целями. Что делать, он учится сам, прямо во время игры.

Видеокарта нужна только **зрению**: на ней работает большая зрительная кора. Остальной мозг
считается на процессоре, потому что там он быстрее (см. раздел «Видеокарта»).

У «Синапса» два тела на выбор:
- **бот Mineflayer** (`minecraft/bot.js`) — без окна, Minecraft 1.20.4;
- **мод для настоящего клиента** (`fabric-mod/`) — окно игры, настоящая картинка, Minecraft 1.21.4.

## Главные принципы

- **Без backprop.** Никакого «обратного распространения ошибки», эпох и GPU. Каждый синапс
  учится сам по себе, по местному правилу (как в мозге): «сработало — усилить, ошибся — ослабить».
  Один пример — одно обновление.
- **Работают только активные нейроны.** В мозге одновременно активны 1–4% клеток. Здесь так же:
  считается только то, куда пришёл спайк. Поэтому быстро даже на процессоре.
- **Учится всю жизнь и почти не забывает.** Новое не стирает старое, как это бывает у нейросетей.
- **Никакого хардкода поведения.** Врождённое только то, что есть у младенца: голод, боль,
  усталость, вкус, испуг, любопытство, тяга к живому. Правил вроде «увидел зомби — бей»,
  «строй дом», «закат красив» нет. Телу можно добавлять только **моторные функции** (умение
  что-то сделать), а когда и зачем их использовать, мозг решает сам.

## Схема: как устроен «Синапс» в Minecraft

```
 ┌──────────────────────┐        ┌──────────────────────────────────────────────┐
 │  Сервер Minecraft    │        │  МОЗГ (Python, brain_server.py)              │
 │  Java 1.20.4         │        │                                              │
 │                      │        │  Чувства тела ──► понятия ──► РАЗУМ          │
 │   ┌──────────────┐   │  JSON  │   (feel_bridge,     (mind_bridge)  цепочки,  │
 │   │ ТЕЛО bot.js  │◄──┼───────►│    mind_bridge)                    навыки,   │
 │   │ (Mineflayer) │   │  TCP   │                                    планы     │
 │   │ 41 действие  │   │        │  ЧУВСТВА (лимбическая система) — 48 эмоций   │
 │   └──────────────┘   │        │  ПРИВЫЧКИ (стриатум + дофамин)               │
 │         │            │        │  ЛИЧНОСТЬ (цели изнутри, дневник, имя)       │
 │   вид от 1-го лица   │        │  ГЛАЗА (зрительная кора, по желанию)         │
 └─────────┼────────────┘        │  ГОЛОС (языковой мозг, по желанию)           │
           └── кадры ──► eyes.py ►│                                              │
                                  └──────────────────────────────────────────────┘
                                   всё выученное сохраняется в minecraft/life/
```

За один «момент»: тело отправляет, что чувствует → мозг обновляет чувства, память и понятия →
выбирает действие → тело его выполняет → мозг учится на результате.

Вместо `bot.js` телом может быть **мод Synapse Body в настоящем клиенте** (`fabric-mod/`). Протокол
у них один и тот же. Мод вдобавок присылает кадр прямо из рендера игры (мир без HUD, 128×128) и
показывает над игрой HUD: имя, возраст, чувство, желание, действие.

## Из чего состоит мозг (отделы)

| Отдел | Что делает простыми словами | Аналог в мозге | Файл |
|---|---|---|---|
| **Сенсорная кора** | Превращает то, что видит и чувствует, в небольшой набор активных «клеток-детекторов» | кора, гранулярный слой | `agent/brain_agent.py` |
| **Привычки** | Каждая активная клетка «голосует» за действие. Хорошо вышло — голос крепнет | стриатум, базальные ганглии | `agent/brain_agent.py` |
| **Дофамин** | Сигнал «лучше или хуже, чем я ожидал» — по нему учатся привычки | дофаминовые нейроны | `agent/brain_agent.py`, `agent/child.py` |
| **Разум: понятия** | На каждую новую вещь («у меня есть доски», «вижу небо») рождается свой нейрон | гиппокамп, энторинальная кора | `agent/mind.py` |
| **Разум: цепочки** | Связь «А обычно было перед Б» крепнет сама → выучиваются причины («бревно ← вижу небо») | префронтальная кора | `agent/mind.py` |
| **Разум: навыки** | Связи «цель → действие». После события мозг прокручивает назад: «вот как я это сделал» | префронтальная кора + гиппокамп | `agent/mind.py` |
| **Разум: рассуждение** | От желаемого идёт назад по цепочкам, пока не найдёт, что можно сделать прямо сейчас | планирование в префронтальной коре | `agent/mind.py` |
| **Привязанность к местам** | Место, где было хорошо и безопасно, становится «моим». Моторная программа «домой» ведёт к самому дорогому месту | клетки места + привязанность | `agent/limbic.py` (`attach_place`), `minecraft/feel_bridge.py` |
| **Карта мест** | Помнит, где видел верстак, воду и т. д., даже когда их не видно. В Minecraft это «Память мест» ниже | клетки места | `agent/crafter_bench.py` |
| **Чувства** | Оценивает каждый миг: приятно ли, ожидаемо ли, кто виноват, могу ли ответить, насколько это дорого. Эмоции — смеси этих оценок, поэтому смешиваются сами (грусть + злость) | лимбическая система, миндалина, островок | `agent/limbic.py` |
| **Развитие как у ребёнка** | Сначала только простые чувства, потом радость/страх/злость, потом ревность и зависть, последними — стыд и вина | развитие по M. Lewis | `agent/child.py` |
| **Сон** | Проигрывает воспоминания и переносит их в долгую память | гиппокамп → кора | `agent/child.py` |
| **Личность** | Цели изнутри: новизна, новые места, голод, боль. Имя, возраст, дневник, память о смертях | гипоталамус, автобиографическая память | `minecraft/personality.py` |
| **Зрение** | Кадр → «сетчатка» (края, цвета) → разреженный код коры. На процессоре 64×64 и 8 тыс. нейронов, на видеокарте 128×128 и 32 тыс. | сетчатка, зрительная кора | `vision/visual_cortex.py`, `vision/visual_cortex_gpu.py` |
| **Движение** | Видит, что существо приближается (оно ближе, чем мгновение назад) и что в зоне что-то движется | зрительная кора MT | `vision/seeing.py` |
| **Узнавание** | Для каждой из 5×5 зон кадра учится называть, что там (бревно, зомби, вода…) и как далеко. Словарь растёт сам; учитель — тело (луч через зону). Узнанное становится понятиями разума и клетками привычек, поэтому на увиденное можно научиться реагировать | нижневисочная кора | `vision/recognizer.py`, `vision/seeing.py` |
| **Режим чувств** | `grow`: глаза сменяют датчики по мере обучения; `human`: только то, что есть у человека; `full`: всё сразу | — | `vision/seeing.py` |
| **Боль** | Игра сама сообщает, что причинило боль: падение, удар (и кто ударил), голод, вода, огонь и лава, кактус, взрыв, удушье, холод. Сила боли — по потерянному HP. Голод «сосёт» тем сильнее, чем меньше еды. Что именно приводит к боли, он выучивает сам. Боль врождённо неприятна: она никогда не становится желанной, даже если совпала с радостью (зомби ударил, пока он бил в ответ). Так же врождённо нежеланна смерть человека или другого ИИ: злость может толкнуть ударить, но убийство не станет целью плана (у Synapse2 одно такое убийство дало облегчение +4.4, и он начал к нему стремиться) | островок, соматосенсорная кора | `fabric-mod`, `minecraft/feel_bridge.py`, `minecraft/brain_core.py` |
| **Страх темноты** | Врождённый, как у людей: в темноте и открытым (ночью под небом, в тёмной пещере) нарастает тревога; укрытие со всех сторон с крышей или свет её снимают — облегчение. В Нижнем мире и Крае нет. Гайд: «ночью безопасно ← укрытие / факелы», «укрытие ← земля, доски» | миндалина | `minecraft/feel_bridge.py` (`dark_unease`) |
| **Боль в руках** | Ломать голыми руками (или не тем инструментом) то, что требует инструмента — камень, руду, — больно; с третьего блока подряд боль растёт, со временем проходит | соматосенсорная кора | `minecraft/brain_core.py` |
| **Возраст** | Прожитое игровое время (дни и часы) — идёт всегда, в том числе пока он копает; «моменты» — это число решений | — | `brain_core.py`, HUD |
| **Получилось / не получилось** | Тело сравнивает себя до и после действия: сдвинулся ли, изменилось ли что в руках, сломался или поставился ли блок, попал ли удар. Если ничего не изменилось, это лёгкая досада; тело называет причину («нет удочки», «рядом нет печи») и чего не хватило — он ищет это в гайде и в справочнике | мозжечок, эфферентная копия | `fabric-mod` (`Motor.outcome`) |
| **Память мест** | Помнит, где видел каждый вид вещей: верстак, камень, воду, дом. Забывает, если пришёл, а там уже нет. Чувство «знаю, где есть X»; поход туда, если это нужно по плану | клетки места | `minecraft/places.py` |
| **Подражание** | Видит, что делает человек рядом: ломает (и чем), ставит, бьёт, ест. То, чем пользуются люди, становится интересным; повторить увиденное самому приятно | зеркальные нейроны | `minecraft/imitation.py` |
| **Понимание речи** | Знает названия всех предметов игры по-русски и по-английски. Понимает объяснения («чтобы получить булыжник, нужна кирка») и просьбы («сделай кирку») | речевые зоны | `minecraft/understanding.py` |
| **Потребность в развитии** | Врождённая, как у человека: радость, когда умеет больше (новый уровень инструментов, новый мир), беспокойство, когда долго ничего не растёт. Следующая ступень пути игры (дерево достижений, клавиша L) становится желанной | потребность в компетентности | `minecraft/development.py`, `knowledge/progress.json` |
| **Гайд** | Вся Minecraft Wiki: обучающие статьи и статьи о каждом блоке, предмете и существе (около 2000). Когда он хочет следующую ступень или не знает, как получить вещь, читает гайд о ней и о том, что для неё нужно. Прочитанное становится слабым убеждением | чтение | `minecraft/guide.py`, `minecraft/guide_reader.py` |
| **Справочник** | Если сломал блок и ничего не выпало, или хочет вещь и не знает как, вспоминает справочник игры: чем добывать, какой рецепт | семантическая память | `minecraft/recall.py` |
| **Слух** | Настоящие звуки игры. Шипение, взрыв, стон, мурлыканье чувствуются с рождения; что значат остальные — выучивается | слуховая кора | `fabric-mod`, `minecraft/feel_bridge.py` |
| **Чтение** | Текст книги → слабые «убеждения» в цепочках разума, которые опыт потом подтверждает или опровергает | языковые зоны | `agent/reading.py` |
| **Голос** | Языковой мозг, прочитавший Minecraft Wiki, отвечает в чате | языковые зоны | `minecraft/voice.py`, `brain_lm.py` |
| **Эпизодическая память** | Помнит каждый прожитый момент (на диске, в пределах бюджета проекта): где был, что сделал, что вышло. В каждый момент за ~0.2 мс находит самые похожие моменты из всей жизни и подсказывает: «в такой ситуации это действие давало хорошее», «после этого действия получалось то, чего я хочу сейчас». Один удачный опыт работает сразу, без тысяч повторений (episodic control) | гиппокамп | `agent/episodic.py` (FAISS) |
| **Инвентарь** | Вещи ценятся по выученной ценности. Вторая единица стоит меньше первой (1 → 1.5 → 1.75 → до 2), поэтому гора земли почти ничего не стоит, а последний алмаз дорог. Положенное в сундук остаётся «своим». Чувство «в сумке есть место»; что выбросить, что отнести в сундук и что взять, выбирает мозг по ценности и по плану, а не тело по списку | ценность, постоянство объекта | `agent/child.py` (`_worth`), `minecraft/feel_bridge.py` (`attention`) |
| **Намерение (фокус)** | Решённое держится: у выбранной цели вес вдвое больше, чем у нового желания, поэтому мелкие соблазны и колебания ценности её не сбивают. Шаг на пути к решённому (верстак для кирки) — не новое желание: намерение остаётся прежним. Продолжать то же действие его тянет, только если оно по опыту приблизило к цели, а не принесло что угодно. Новое желание заменяет решённое, только если побеждает два раза подряд, а не от одного взгляда. Брошенное («не вижу пути», «не выходит») какое-то время тянет вдвое слабее, поэтому нет метаний «плита ↔ булыжник» каждую секунду. Не умея чего-то добиться, он сначала пробует то, что ради этого ни разу не пробовал; после первой пробы тяга пропадает. Тяга тем сильнее, чем чаще эта цель не удавалась, и исчезает, когда он умеет. Так ложная уверенность («бег даёт сытость») не держит его в цикле: в проверке правильное действие находится за 2–8 моментов вместо 56–64. В журнал каждого решения пишется, что его определило: навык, привычка, память, полезность, новизна, «продолжай» Бросает он её, только если добился; если не выходит (после каждой неудачи держаться легче бросить, после 3 подряд бросает); если пути больше нет; если появилось что-то намного важнее; если опасность — тогда отвлекается, а после опасности возвращается к делу. Каждая смена цели записывается в события с причиной. Желание вещи от неудачи возникает, только если действие выбрал сам план, а не случайная проба | префронтальная кора (рабочая память) | `agent/mind.py` (`intent`, `commit`) |
| **Причина или совпадение** | Условием он считает только то, что бывает перед событием заметно чаще, чем вообще: минимум на 20% и хотя бы вдвое. Небо, «в верхнем мире», «вижу траву» и вещи, которые он таскает всегда, ничего не объясняют. Прочитанное (рецепты, гайд) освобождено от этой проверки, опровергнуть его может только собственный опыт. Если известная причина события была на месте, посторонние совпадения почти не набирают силу (блокирование, эффект Камина). Справочник засевает стартовые оценки «с каким инструментом добывается лучше» | префронтальная кора, ассоциативное обучение | `agent/mind.py` (`_specific`, `_learn_chain`, `told_pre`) |
| **Что сделал на самом деле** | Учится он только на том действии, которое тело действительно выполнило. Каждый ответ телу пронумерован, и тело в отчёте называет номер. Если отчёт о другом моменте (переподключение), действие прервано (смерть, пауза) или его не было, этот шаг ничему не учит. Вето, рука экспериментатора и действие, которого у тела нет, записываются как сделанное; вмешательство помечается в журнале. «Как часто моё действие срабатывало» — это доля попыток, засчитанных до исхода, поэтому оценка никогда не больше 1 (раньше у Synapse1 так было в 1712 записях из 9993, до 7.0). Действие считается способом получить цель, только если с ним цель приходит хотя бы вдвое чаще, чем в той же обстановке без него: темнота после заката приходит, что бы он ни делал, и действие «на закате смотрел вверх» причиной не становится | базальные ганглии, префронтальная кора (контингентность) | `agent/mind.py` (`acted`, `_ao_attempt`, `ao_effect`), `minecraft/brain_core.py` (`did`), `fabric-mod` (`Motor`: `id`, `timeout`, `interrupted`) |
| **Что что даёт** | Тело сообщает про каждый сломанный блок, что попало в сумку в следующую секунду (или ничего). Он считает это сам: «дубовое бревно давало бревно 20 раз из 20», «трава даёт землю», «листва — саженцы и палки». Когда шаг плана — «иметь X», руки целятся в то, что давало X; если его не видно, он идёт искать, а не копает траву рядом. Условием для «действие → результат» он считает только то, что было при успехе почти всегда и заметно чаще, чем вообще (трава в поле зрения — не условие) | кора (аффордансы), обучение по опыту | `minecraft/yields.py`, `minecraft/feel_bridge.py` (`attention`), `agent/mind.py` (`ao_context`) |
| **«С этим лучше»** | Кроме «без этого не бывает» (цепочки), разум помнит, с чем цель удаётся чаще. Для каждой цели он считает удачи с каждой вещью при себе, в руке, на себе и без неё. Совет из книги засчитывается как пара удачных попыток, которые опыт уточняет. Выбирая план, он сравнивает «сразу» и «сначала добыть то, с чем выходит чаще». Пример мысли: «хочу убить зомби; с мечом в руке выходит чаще (75% против 36%); для меча в руке нужен меч; сейчас делаю: меч» | префронтальная кора (оценка вариантов) | `agent/mind.py` (`helpers`, `tell_helps`) |
| **Любопытство с умом** | Мастерить новое интересно, но не из того, что нужно планам: всей цепочке к текущей цели и следующей ступени развития. Доски на пуговицы он не потратит, если они нужны на верстак и кирку. Желание вещи от неудачи возникает, только если неудачное действие было шагом плана. Случайная проба только учит | — | `minecraft/feel_bridge.py` (`plan_needs`, `spends`), `minecraft/brain_core.py` |
| **Злость и бой** | Злость — на того, кто, по его опыту, приносит беды (виноватый выучивается). Пока виноватый рядом, злость толкает ударить; сила толчка равна злости. Это порыв, а не приказ: страх того, во что удар обошёлся раньше, может его остановить, а сильная злость может прервать текущий план. Моторика «ударить»: подойти к выбранному (кого — решает мозг: того, на кого злится, иначе по опыту), смотреть на него и бить, когда рука готова (перезарядка удара), пока он не упадёт или не уйдёт, не дольше 5 с. Потом мозг решает снова. Ударить виноватого приятно, и тем сильнее, чем сильнее удар: тело сообщает настоящий урон (кулак 1, меч 4–7). Убить своей рукой того, кто угрожал, — облегчение (понятие «убил:X»); он знает, что у него в руке (понятие «в руке:X»). Когда его бьют, он ищет в гайде, как отбиться: «оружие снижает шанс погибнуть», «удар с мечом в руке ранит», «меч = 2 доски + палка». Цепочку «убить ← меч в руке ← меч ← доски, палка» опыт подтверждает или опровергает | миндалина, гипоталамус (агрессия) | `agent/child.py` (`tendency`), `agent/mind.py`, `fabric-mod` (`Motor.fight`), `minecraft/feel_bridge.py` |
| **Память сундуков** | Помнит каждый сундук: где стоит и что в нём лежало, когда открывал его последний раз. Чувство «у меня есть X в сундуке»; если по плану нужно X, а с собой его нет, идёт к нужному сундуку | клетки места и объектов | `minecraft/places.py` |

**Где хранятся знания.** Навыки, цепочки и ценности — это веса синапсов (`life/mind.npz` и др.),
а не отдельные файлы с кодом навыков.

**Потолков у разума нет.** Понятия растут, пока есть память: при заполнении их место удваивается,
а цепочки хранятся разреженно — только реальные связи, в среднем около 60 на понятие. Поэтому миллион
понятий занимает столько, сколько весят их настоящие связи. Рассуждение проходит цепочку до конца,
любой длины. Ценность средств тоже течёт по всем звеньям. Терпение к цели выучивается: он держит
цель столько, сколько раньше уходило на её достижение. Таблица навыков удваивается, когда в неё
становится тесно. Ограничивает только машина: весь проект ≤ 100 ГБ на диске (`world.json` → `limits`),
на диске всегда остаётся ≥ 10 ГБ свободными, 3 ГБ оперативной памяти не отдаются под рост
(`minecraft/limits.py`). Вдаль он думает, как человек: ставит подцели. Цель «алмаз» ведёт к «железной
кирке», та к «железу», и так дальше; ни одна мысль при этом не держит в голове всю цепочку целиком.

## Видеокарта: что на ней и почему не всё

Замеры на RTX 3090 (этот ПК):

| Что | Процессор | Видеокарта |
|---|---|---|
| Один шаг мозга агента (около 60 активных синапсов) | **23 мкс** | 366 мкс, в 16 раз медленнее |
| 256 воспоминаний за раз (повтор опыта) | 1.4 мс | 0.95 мс, в 1.5 раза быстрее |
| Зрение: 8 тыс. нейронов, кадр 64×64 | **2 000 кадров/с** | медленнее |
| Зрение: 65 тыс. нейронов, 128×128, 64 кадра пачкой | 170 мс | **7 мс, в 24 раза быстрее** |

Почему так. Мозг агента за шаг трогает десятки синапсов из миллиона. Видеокарта тратит на запуск
каждой операции больше времени, чем процессор на всю работу. Поэтому привычки, разум и чувства
остаются на процессоре. Языковой мозг тоже: он читает текст строго по порядку, а распараллелить
такое чтение видеокарте нечем.

**Что перенесено на GPU — зрение** (`vision/visual_cortex_gpu.py`):
- кора в 4 раза больше (32 768 нейронов) и картинка в 4 раза крупнее (128×128);
- в игре обрабатывается 14 400 кадров/с без развития и около 950 кадров/с с развитием;
- один живой кадр вместе с сетчаткой и развитием занимает 1.5 мс;
- правила обучения те же, локальные, без backprop;
- сетчатка на GPU совпадает с процессорной на 99.8%.

**Живое зрение считается на процессоре.** Один кадр за раз на процессоре — 8 мс, а на видеокарте,
которая одновременно рисует Minecraft, — 46 мс (замерено в живой игре). Видеокарта нужна для пакетного
развития глаз на тысячах кадров.

Развивать большую кору на записях или видео можно быстро: `python vision/develop_gpu.py <папка>`.
В игре она включается сама, если есть видеокарта: `run_synapse.py --eyes` или
`brain_server.py --see`. Флаг `--device cpu` возвращает старую кору.

## Тело в Minecraft (`minecraft/bot.js` или `fabric-mod/`)

**Чувствует:** клетки вокруг (что где лежит, можно ли пройти), мобов (кто и насколько далеко),
здоровье, голод, броню, что в руке и в инвентаре, ночь, небо, «застрял», «до верстака дотянусь»,
попал ли его удар, что стало с блоками, которые он сам поставил, тон слов игрока в чате.
С `--eyes` ещё и видит картинку игры.

**Может сделать (41 действие):**
- движение: вперёд/назад/вбок, повороты, прыжок, бег, Shift, взгляд вверх/вниз;
- работа руками: копать перед собой/вниз/вверх, ставить блоки, подняться, поставив блок под себя;
- бой и снаряжение: удар, надеть лучшую броню, взять оружие или инструмент;
- крафт и быт: смастерить новое/снаряжение, печь, еда, сон в кровати, выбросить мусор;
- жизнь: рыбалка, приручение, сундуки (положить/взять/поставить), торговля, чтение книги;
- **моторные программы** (куда их направить, выбирает мозг): подойти к увиденному, добыть
  увиденный блок, смастерить задуманное, дойти до самого дорогого места («домой»), уйти исследовать,
  поставить рамку портала в Нижний мир из обсидиана.

Знает все **729 рецептов** и **110 достижений** версии 1.20.4 (`minecraft/knowledge/`).

**Мод Synapse Body** (`fabric-mod/`, Minecraft 1.21.4) умеет те же 41 действие под теми же
номерами, поэтому выученное переносится. Плюс **19 действий рук как у игрока**: точный поворот
головы, ЛКМ и ПКМ по перекрестию, удержание ПКМ, слоты 1–9, F, Q. С ними можно строить мосты,
черпать ведром, бросать жемчуг и око Края. Разница в том, что это настоящий клиент:
- крафт идёт через книгу рецептов игры, как у игрока;
- ходьбу по пути делает Baritone;
- картинка для глаз берётся из рендера самой игры.

Подробнее: [`fabric-mod/README.md`](fabric-mod/README.md). Собран и проверен без игры; живого
запуска в игре ещё не было.

## Языковой мозг (`brain_lm.py`)

Предсказывает текст побитово. Вместо «внимания» трансформера:
- **гранулярный слой** — миллионы детекторов контекста (последние 1–8 букв, слово, пара слов);
- **гиппокамп** — находит, где такое уже было, мгновенно (по хешу), без перебора контекста;
- **мозжечок** — смешивает подсказки и учится на своих ошибках;
- **семантическая память, прайминг, рабочая память, «интерес к разговору»** — держат тему.

Цена одного символа не растёт с длиной текста: контекст фактически неограничен.

## Поколение 2 (с 26.09.2026)

Первое поколение училось на сломанной механике: чужие действия засчитывались не тем, оценки успеха
доходили до 7, боль и убийство человека стали желанными, 65% действий составляла ходьба, которая
обрывалась через 8 секунд. Оно в архиве (`world/archive/gen-20260926-1402`, можно вернуть).
Поколение 2 родилось с нуля (осталось только выученное зрение) в нетронутом лесу у (−3012, 74, −2901):
`minecraft/new_generation.py`, `minecraft/generation.py`, `world/generation.json`.

- **Детство без монстров.** Первые 50 игровых дней монстры не появляются. Голод, вода, падения и страх
  темноты остаются. На 51-й день монстры приходят сами.
- **Врождённые влечения.** Страх темноты ночью, голод и раны делают желанным состояние, которое их
  прекращает («спокойная ночь», «сыт», «здоров»), даже если он там ни разу не был; путь он ищет сам.
  Сила нужды нелинейна (лёгкий голод почти не мешает, голод при сытости 0 перевешивает всё), а
  сильная нужда прерывает намерение, как опасность. В проверке укрытие находится в 14–24 ночах из 25,
  без влечения — в 0–19.
- **Приёмы.** Путь, который привёл к цели, запоминается целиком с первого раза (только шаги, после
  которых что-то изменилось) и повторяется, пока навык молод. Первые ночи даются на 22% быстрее.
- **«Сработает ли здесь».** Выученная модель: при каких условиях каждое действие что-то меняет
  (плавить без печи — ничего). Бесполезные здесь действия тянут слабее.
- **Моторика.** Ходьба (Baritone) длится, пока тело приближается к цели (до минуты), а не 8 секунд; не
  приближается 5 с или ранен — останавливается. В воде тело само держит голову над водой. Новое движение «поставить
  блок над собой» (крыша): укрытие «три блока вниз и крышка» стало физически возможным.

- **Схемы рук** (`minecraft/schemas.py`). Выученное и общее, а не про одну вещь: «смастерить T даёт T,
  когда книга показывает, что T можно сделать», «добыть T даёт то, что T даёт при ломании», «подойти к T
  — и T рядом, когда T видно». Выученная на досках и палках, схема сразу работает для верстака, которого
  он ещё не делал: хочет верстак, из досок можно — мастерит, а не идёт исследовать мир. Хочет бревно и
  видит дерево — идёт к дереву.
- **Книга рецептов** (действие «открыть книгу рецептов»): тело открывает инвентарь и читает рецепты,
  которые игра уже открыла (что, из чего, нужен ли верстак). Каждый новый рецепт становится цепочкой в
  голове. Это обычный интерфейс игры, поэтому канал `recipe_book` открыт у всех, включая Synapse3.
- **Нужда против беспомощности.** Сильную нужду (голод) он добивается, даже если раньше не выходило.
- **Путь достижений без чужих камней.** Из вариантов шага («Stone Age»: булыжник, глубинный булыжник,
  чернокамень) сильно хочется того, с чем он уже знаком; чернокамня в обычном мире нет.
- **Темп мира.** Фоновые клиенты считали тело «отошедшим» (клавиши жмёт мозг, а не человек) и снижали
  частоту кадров; глаза и чувства ждали кадр, и мир шёл 22 тика/с вместо 60. Теперь ограничение только
  у свёрнутого окна.

- **Воображение** (`minecraft/imagine.py`, этап 3 роадмапа). Перед действием он проигрывает в голове путь
  к цели из выученных кусков: рецепты с количествами («кирка ← 3 доски + 2 палки + верстак»), что что даёт
  («курица → курятина»), схемы рук, где что лежит, и то, что уже приводило к цели. Так находится путь,
  которого он ни разу не проходил целиком («иду к курам → бью курицу → ем»). Выполняется первый шаг, в
  следующий момент путь представляется заново. Путь пишется в события («Представил путь: …»). Случайное
  совпадение («так уже выходило») используется, только если ничто другое не объясняет, как получить
  нужное, и только если повторилось хотя бы трижды.
- **Упорство.** Решённое весит втрое больше нового желания; новое должно победить три раза подряд; после
  трёх неудач — бросает. Опасность и нужда перебивают решённое только ради того, что их снимает (поесть,
  укрыться), а не ради любой цели.
- **Без артефактов.** Запомненный приём хранит только шаги, которые по знанию ведут к цели (доски, палки для
  кирки), а не траву, сломанную по дороге. «Попробовал ударить — бить некого» не считается пробой.
- **Охота.** Убив животное, тело подходит к месту и подбирает выпавшее; убегающего преследует до 15 с.
  Тело больше не подсказывает «нужен хлеб», когда нечего есть: что съедобно, он узнаёт сам.

- **Голод хочет «поесть».** Каждый съеденный кусок — успех (сытость 18, «сыт», одним куском не набрать, и
  охота выглядела бесполезной). Облегчение «укрылся» приходит раз за укрытие, а не каждую секунду.
- **Дом и карта.** Где ночью был закрыт со всех сторон — мой дом (помнит до трёх, главный — где чаще).
  Понятия «знаю, где дом», «я дома». Воображение для спокойной ночи: домой, а дома — закрыться. Места,
  где было больно (падение, огонь, вода, удар), помнятся: путь туда воображение считает хуже.
- **Вечер.** Желание укрыться появляется на закате (пока тело на открытом месте), а в темноте на открытом
  месте растёт до предела — врождённый суточный ритм.
- **Страх высоты.** Рефлекс тела: идя к обрыву в 4 блока и выше (или к лаве), тело приседает — и не
  срывается. Вода внизу — не обрыв.

- **Нужда не ходит кругами** (день 42). Голод больше не цепляется за шаг, который был рядом, когда он ел
  («трава», «небо»), если может представить путь к еде (что съедобно, где оно) или если шаг трижды не
  вышел. То, что здесь почти никогда не работает («съесть», когда есть нечего), выученная модель
  «сработает ли здесь» отодвигает в самый конец (Synapse3 жал «есть» 170 раз подряд с одними палками в
  сумке). «Напрасно» теперь сравнивается с остальными действиями: если напрасным было всё (еды рядом
  нет), он всё равно идёт путём, который представил, например ищет дальше.
- **Куда не дойти.** Если дорога к месту застряла, это место (дом, сундук, запомненная вещь) какое-то время
  не выбирается снова. Ходьба останавливается, если 5 с не становится ближе к цели (барахтается в воде,
  ходит кругами), а не только когда стоит на месте: исследование больше не тянется по минуте.
- **Исследование вдаль.** Тело идёт исследовать дальше в ту же сторону, изредка сворачивая. Случайное
  блуждание оставалось у места рождения, где животные к 40-му дню были съедены.
- **Дом помнится после перезапуска.** Раньше дома сохранялись, но не загружались. То же было с тем, что он
  знает как съедобное (что пробовал сам): теперь это тоже сохраняется (`growing/edible.json`).
- **Нужда пересматривает старый шаг.** Намерение «поесть», выбранное сытым, шло через шаг «увидеть траву».
  Когда пришёл голод, он держался за этот шаг и уплывал в море искать траву с тремя яблоками в сумке:
  нужда прерывала только другие цели, а не свою. Теперь каждые 10 шагов, если появился прямой путь
  (еда в сумке), шаг бросается. Экзамен «поесть»: 4293 тика → 120.
- **Путь Baritone не рисуется в мире** (красная линия, зелёные столбы цели): глаза учатся на этой картинке.
- **Ложные связи проверяются делом** (`agent/mind.py`: `links`, `_testable`, `_links_seen`, `_links_settle`).
  «Для еды нужно небо / трава / кнопка в сумке» выучивалось по совпадению: он всегда ел на улице с кнопкой
  в сумке. Одно наблюдение не отличает такое совпадение от причины. Теперь выученное (не прочитанное)
  условие проверяется двумя способами:
  - **опытом.** Иногда он пробует сделать дело без условия. Проверка короткая: столько, сколько дело
    обычно занимает. Пока она идёт, действие, которое добывает это условие, запрещено.
  - **наблюдением.** Каждый раз, когда дело случилось без условия, это записывается навсегда. Раньше
    сила связи была скользящим средним, и такие случаи смывались, стоило ему снова полезть за небом
    перед едой.

  Если без условия вышло, связь ложная и больше нигде не используется: ни в цепочках, ни в ценности
  средств, ни в воображении, ни в «так уже выходило», ни в «продвинулся ли я», ни в выборе мест.
  Трижды без условия не вышло — связь подтверждена и больше не проверяется. Рецепты из книги так не
  проверяются. Ещё два фильтра:
  - «с этим получается лучше» принимается, только если разница больше, чем объясняет везение
    (интервал Уилсона);
  - «из блока X выпадает Y» — только если выпало хотя бы дважды: иначе вещь, лежавшая рядом, тоже
    считалась бы выпавшей.

  Проверка на 8 сидах: ложная связь находится 8 из 8, настоящая сохраняется 8 из 8 и проверяется не
  больше трёх раз.
- **План исполняется, а не голосуется** (26.09, вечер). Раньше действие выбиралось голосованием примерно 15
  «голосов»: привычка, навык, память, страх, «напрасно», «не сработает», «не пробовал», «полезное», «так
  выходило», воображение, приём. План из воображения был лишь одним из них, и его то и дело перебивали: в
  голове план, в руках другое. Теперь так:
  - **Цель → план.** Если воображение может проложить путь к цели из выученного (рецепты, что с чего
    падает, где что лежит, что съедобно), этот путь и есть план, а не цепочка «что было рядом».
  - **План исполняется.** Следующий шаг плана и есть действие. Прервать его может только сильная эмоция;
    иногда (3%) он пробует что-то другое. Остальные голоса решают, только когда плана нет.
  - **Шаг с ожиданием.** «Рублю бревно — жду бревно». В следующий момент он проверяет, пришло ли
    ожидаемое. Если пришло, план продолжается и терпение к цели продлевается. Если нет, запоминается,
    как часто такой шаг не срабатывает, и воображение начинает считать его менее вероятным и ищет другой
    путь. В событиях видно «✓ … ждал бревно, получил» и «✗ … ждал бревно, не вышло (3 из 4)». Над головой:
    «хочу: … · шаг: … · жду: …» по-русски.
  - **Исправлена старая ошибка воображения.** Когда всё для вещи уже было (бревно для досок), оно
    выбирало «доски появятся сами» — шаг без действия, — и плана не было. Именно когда можно было
    скрафтить, он не знал, что делать.
- **Воображение: ещё три исправления.**
  - **Длинные планы.** Горизонт вырос с 8 до 16 шагов. Булыжник с нуля («бревно → доски → верстак →
    палки → кирка → найти камень → добыть») раньше не помещался, и он шёл по ложной цепочке.
  - **Порядок шагов.** С пустой сумкой план начинался с «скрафтить доски»: воображение считало
    бревно уже добытым, потому что его добывал шаг, стоявший в плане позже.
  - **Добываемое не крафтится.** Гайд сказал «булыжник ← камень + кирка», и воображение сделало из
    этого рецепт. Теперь то, что с чего-то падает, добывают, а не крафтят.
- **Нужда определяет желание.** Состояние, которое снимает нужду (поесть, спокойная ночь), желанно ровно
  настолько, насколько есть нужда. Сытым он больше не идёт искать морковь: в Minecraft сытым есть нельзя,
  а от неудачных попыток он переставал доверять шагу «съесть».

## Готовые знания: какие каналы открыты

Кроме собственного опыта, в мозг может попадать готовое: гайд (Minecraft Wiki), справочник рецептов
и инструментов, путь достижений и уровни инструментов как «рост», подражание людям, слова людей,
книги в игре, детские привычки из MiniCraft. Каждый канал выключается в `world.json` → `"knowledge"`
для всех или для одного ИИ. Выключенный канал до разума не доходит вовсе (`minecraft/knowledge.py`).
Врождённое остаётся всегда: тело, чувства, боль, голод, страх темноты, любопытство.

Каждый запуск записывается в `life/<имя>/runs/<время>.json`: коммит, есть ли незакоммиченные
правки, открытые каналы, переключатели, настройки мира и машина. Сказать «научился сам» честно
можно только про жизнь, где нужные каналы были закрыты.

Проверки без игры (секунды): `agent/mind_tests.py` (своё действие, оценки ≤ 1, совпадение, настоящая
причина, два способа) и `minecraft/contract_tests.py` (номер ответа, устаревший и прерванный отчёт,
рука экспериментатора, чего нет у тела, закрытые каналы).

## Слабые места (честно)

- **Память:** языковой мозг занимает ~6.7 ГБ RAM, а трансформер — ~13 МБ.
- **Не «сверхразум».** Языковой мозг хорошо предсказывает текст, но не рассуждает словами. Голос
  бота в основном шаблонный.
- **Игру не пройдёт.** По Crafter за неделю стоит ждать дерево, верстак, деревянную кирку, еду и
  драку с зомби, но не железо, алмазы и дракона.
- **Дом сам не строит**, «закат — это красиво» не подтвердилось.
- **Зрение слабое**: главные источники — прямые сенсоры тела.
- **Идея не с нуля.** Почти каждый кирпич известен в науке (сжатие PAQ, TD(λ), hindsight replay,
  внутренняя мотивация, разреженное кодирование). Новое — сборка по отделам мозга, связи между
  ними, скорость и проверка всего вместе.

## Как запустить на ПК

Нужны Python 3.10+, Node 18+, Java 17+, ~4 ГБ свободной памяти. Подробно — в
[`minecraft/README.md`](minecraft/README.md).

```bash
cd synapse-brain/minecraft
pip install -r requirements.txt && npm install
python setup_server.py --accept-eula          # сервер Minecraft (принятие EULA Mojang)
cd server && java -Xmx3G -jar server.jar nogui # в отдельном окне
python run_synapse.py --voice --eyes          # мозг + тело
```

Флаги: `--eyes` (видеть картинку), `--blind` (действовать только по зрению), `--voice` (отвечать
в чате), `--no-feelings` (без лимбической системы).

**Мир с несколькими ИИ и панель мониторинга:** `python world.py --accept-eula`. Поднимаются
сервер, мозги, клиенты и панель на http://127.0.0.1:8765, где видно, кто что решает и кто лучше.
Настройка в `minecraft/world.json`, подробности в [`minecraft/README.md`](minecraft/README.md).

**Тело в настоящем клиенте.** Нужен сервер 1.21.4 (`python setup_server.py --accept-eula --version 1.21.4`),
затем `python run_synapse.py --body mod --eyes`. Клиент, Fabric, Baritone и мод поставятся сами.
Откроется окно игры с HUD Синапса. Подключиться: клиент Minecraft Java 1.20.4 →
`localhost`. Спросить в чате: «как ты себя чувствуешь?», «что ты любишь?», «о чём думаешь?».
Прогресс пишется в `life/progress.csv`.

## Ядро v5 (27.09.2026): одна модель мира, один планировщик, цели от нужд

Разбор архитектуры показал, что проблема не в отдельных поломках, а в устройстве:
- знание «что к чему ведёт» хранилось в восьми местах, и они противоречили друг другу;
- причины выводились из совпадений: небо перед едой, кремень в сумке;
- действие выбирало голосование примерно 15 эвристик;
- цели брались из выученной «приятности» чего угодно.

Ядро v5 (`minecraft/core5.py`) заменило всё это в принятии решений. Старый разум остался для восприятия,
эмоций и памяти, но больше не решает.

- **Модель мира из операторов.** Оператор — что мои руки делают с видом вещи: «добыть бревно», «сделать
  доски», «съесть яблоко», «исследовать». Каждая попытка записывается: что стало правдой, что пришло в
  сумку, что ушло из неё.
  - **Нужное условие.** Условие нужно для результата, только если оно было при каждом успехе и без него
    результат хотя бы дважды не пришёл. Небо, которое всегда рядом, так не пройдёт.
  - **Из чего сделано.** Что при успехе ушло из сумки, из того вещь и сделана, с количеством.
  - **Прочитанное.** Книга рецептов и справочник — начальные гипотезы, мои попытки их перекрывают.
  - **Состояния от вещей.** «Верстак рядом, когда он в сумке» — выучено по наблюдению или прочитано.
- **Один планировщик.** Самый дешёвый путь от того, что есть, к цели. Каждый шаг ждёт свой результат, в
  следующий момент путь строится заново.
- **Цели, по порядку:**
  1. нужда тела (голод, ночь), столько, сколько она сильна;
  2. новое, что я вижу, как получить, — сперва то, что можно сделать прямо сейчас, и то, что нужно многим
     другим действиям (доски, верстак, кирка), а не кнопки;
  3. проба действия, которое я здесь ещё не пробовал;
  4. исследование.
- **Привычки и голосование** в решениях не участвуют.

Проверка на копии памяти Synapse1:
- сытый с пустой сумкой: «хочу деревянную кирку: бревно → доски → палки → … → верстак → кирка» — рубит ель;
- голодный: «ударить корову → съесть говядину».

Одно решение занимает 2–9 мс. Тесты ядра: нужное — то, без чего не вышло; ингредиенты — то, что израсходовано;
голодный ест первым делом.

Synapse1 живёт дальше со своей памятью, но решает уже ядро v5. Проверка по критерию перенесена на ночь на

### Выживание ночью (27.09, 15:00)

Они гибли почти каждую ночь. Цепочку «закопаться → накрыться» рвали три вещи, и все три исправлены без
прописанного поведения:

- **Страх темноты был ступенчатым.** Он учитывал только стороны, закрытые и у ног, и у головы:
  - первая выкопанная ступень его не уменьшала, поэтому не подкреплялась;
  - после второй он падал ниже порога нужды при открытом небе над ямой, так что ставить крышу было незачем.

  Теперь страх плавный. Половина его — открытое небо, половина — восемь половинок сторон (у ног и у головы).
  Каждый блок между мной и ночью немного его снимает:

  | Где стою | Страх |
  |---|---|
  | Поле | 1,44 |
  | Яма в 1 блок | 0,81 |
  | Яма в 2 блока, небо открыто | 0,36 (ещё нужда) |
  | Яма под крышей | 0 |
- **Облегчение и опасность помнятся по ситуациям.** Ситуация — это небо, темнота, стены вокруг, испытываемые
  нужды. У каждого действия хранится 12 последних попыток в каждой из 64 ситуаций.
  - Раньше ночные уроки вытеснялись из памяти за день: у действия хранится 40 последних попыток.
  - Раньше опасность считалась в среднем за жизнь: исследовать днём безопасно, ночью смертельно, а в среднем
    выходило «так себе».
- **Проба под нуждой — то, чего не пробовал именно здесь.** Раньше пробовалось только то, чего не делал ни
  разу в жизни. «Блок над головой» однажды не прилип на ровном месте, и в яме, где он спасает, его больше не
  пробовали. Облегчение от действия засчитывается там, где оно было:
  - копать глубже в яме больше не облегчает;
  - рассвет не считается облегчением, которого я добился сам.
- **Любопытство не идёт туда, где было дорого.** Если шаг «ради интереса» здесь в среднем стоил ≥ 4 здоровья,
  я пережидаю.
- **Дом.** Его безопасность ночью меряется по опыту: «сколько раз там было безопасно», а не «дошёл ли».

Тесты: страх убывает по шагам; облегчение считается там, где оно было; в яме пробуется то, чего там не
пробовал; ночь и день помнятся раздельно (и после сна).

Первые 15 минут после этого: 17 смертей, ни одного «укрылся». Помешали две вещи:
- **Перебор выдыхался.** На открытом месте всё перепробовали за ночь, а облегчившее один раз больше не
  повторяли. Под страхом оставалось только «исследовать» (113 раз из 159).
- **Голод ночью был сильнее страха.** Уже при еде ≤ 7 они уходили в темноту искать еду.

Поэтому в 15:28:
- **Проба под нуждой устроена как у кошки в ящике.** Оценка действия здесь = (облегчило + 1) / (попыток + 2):
  - непробованное — 0,5;
  - облегчившее — выше, его повторяют сразу;
  - не облегчавшее — ниже, его отпускают;
  - сделанное под этой нуждой в другом месте весит вполовину.

  Так пробуют, только если нужду когда-либо снимало простое действие руками прямо на месте (страх — да). Если
  нет (голод), её ищут: план, проба нового, исследование.
- **Страх в открытой ночи сильнее умеренного голода:** 0,9·открытость, в поле 3,2. Голод перевешивает только
  при еде ≤ 2.
- **Рискованный шаг** (здесь в среднем ≥ 4 здоровья) делается только ради горящей нужды (≥ 2). Иначе
  пережидается: голодный в закрытой яме ночью не выходит, если выход там уже стоил дорого.
