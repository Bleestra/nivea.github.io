# Синапс в Minecraft — запуск на своём компьютере

Синапс — автономный агент на SynapseBrain: сам решает, что делать, учится на своём опыте
(любопытство к новому, исследование, голод, боль, страх, достижения), ведёт дневник, помнит свою
жизнь между запусками и отвечает в чате.

## Что нужно
- **Python 3.10+** и **Node.js 18+**
- **Java 17+** (для сервера Minecraft)
- ~5 ГБ свободной памяти (разум ~1 ГБ, голос ~1.2 ГБ, сервер ~2–3 ГБ); видеокарта не нужна

## Установка (один раз)
```bash
git clone https://github.com/Bleestra/nivea.github.io && cd nivea.github.io
git checkout claude/ai-architecture-alternatives-heymnc
cd synapse-brain/minecraft
pip install -r requirements.txt
npm install
python -m playwright install chromium          # только если нужно зрение (--eyes)
python setup_server.py --accept-eula           # скачать сервер 1.20.4 (EULA Mojang: https://aka.ms/MinecraftEULA)
```

## Запуск
1. Сервер (отдельное окно): `cd server && java -Xmx3G -jar server.jar nogui`
   В консоли сервера: `op SynapseBrain` (нужно только для самопроверки).
2. Синапс:
   ```bash
   python run_synapse.py --voice            # + --eyes, чтобы он видел картинку игры
   ```
   Первый запуск: «детство» в песочнице MiniCraft (~1 мин) и выращивание голоса — чтение
   Minecraft Wiki с Hugging Face (~10 мин). Дальше старт за секунды.
3. Заходите в игру (Minecraft Java 1.20.4 → Сетевая игра → `localhost`) и говорите с ним в чате:
   «кто ты?», «о чём думаешь?», «что ты умеешь?», «как получить булыжник?», «как ты себя чувствуешь?»,
   «что ты любишь?», «чего ты боишься?»,
   «How do you craft a crafting table?»… На вопросы о себе и «как получить X» он отвечает из своего
   разума (выученных цепочек и компетентности), на остальные — голосом.

**Оставить надолго.** `run_synapse.py` теперь живёт сам: если тело отвалится от сервера (или упадёт),
оно переподключится через 10 секунд, если упадёт разум — перезапустится. Каждые 2000 шагов в
`life/progress.csv` пишется строка: возраст, стадия развития, сколько понятий, достижений, открытых
вещей, смертей и что он чувствует — по ней видно, растёт ли он. Для скорости на ПК лучше без `--eyes`
(глаза — самая медленная часть); с 3090 это не связано: мозг работает на процессоре.

Ctrl+C — Синапс «засыпает», всё выученное остаётся в `life/` (синапсы привычек `brain.npz`,
растущий мозг `growing/` — понятия, цепочки, навыки, чувства, привязанности, память, стадия
развития; `self.json`, дневник `self_diary.md` с мыслями «думаю: …» и чувствами «чувствую: …»).
Он рождается «младенцем»: сначала только довольство, дистресс, интерес, отвращение, испуг; остальные
чувства появляются по мере развития (см. раздел «Чувства» в [`../README.md`](../README.md)).
Говорите с ним в чате — тон ваших слов («молодец», «осторожно», «нельзя») он воспринимает как
интонацию родителя. `--no-feelings` — прежняя версия без лимбической системы. Удалите `life/`, чтобы он родился заново.

Проверка тела (все действия): `node bot.js --version 1.20.4 --name Tester --selftest`
(бот должен быть оператором: `op Tester`, пока он в игре — оператор для ещё не заходившего ника в
офлайн-режиме может не примениться; тогда просто запустите тест ещё раз). Ожидается 26/26 `true` (для рыбалки и приручения тест проверяет только, что действие выполняется без
ошибок, а не результат).

## Мир с несколькими ИИ и панель мониторинга

Один сервер Minecraft 1.21.4, в нём несколько Синапсов: у каждого свой мозг, память и настоящий
клиент игры. Первый ИИ играет в большом окне, за ним вы и следите. Остальные играют в маленьких
окнах в фоне. Их **нельзя сворачивать**: свёрнутое окно ничего не рисует, и ИИ слепнет.

```bash
python world.py --accept-eula       # первый раз: скачает сервер (EULA Mojang: https://aka.ms/MinecraftEULA)
python world.py                     # столько ИИ, сколько потянет ПК (до 4)
python world.py --instances 3       # ровно 3
python world.py --dashboard-only    # только панель (жизни хранятся на диске)
python world.py --stop              # из другого окна: все сохраняются и засыпают
```

**Скорость игры.** Мир идёт быстрее обычного: `tick_rate` в `world.json` задаёт стартовую скорость
(20 — обычный Minecraft). Дальше `world.py` сам держит её такой, чтобы мозги успевали: пока мозг думает,
должно пройти не больше ~5 тиков, как у человека на реакцию. Верхний предел — `max_tick_rate`.
Ускоряется всё: мобы, день и ночь, печи, а также ходьба и копание самого Синапса. В обычном Minecraft
клиент не умеет ускоряться вслед за сервером, это делает мод. Темп виден на панели во вкладке
«Чувства и вещи».

**Сколько ИИ потянет ПК.** Один ИИ — это мозг со зрением (около 2.4 ГБ, замерено) плюс клиент
игры (около 2.5 ГБ), всего около 5 ГБ ОЗУ. Ещё около 1.2 ГБ видеопамяти и 3 потока процессора.
`world.py` смотрит свободные ресурсы и пишет, почему выбрал именно столько. На ПК с 32 ГБ для 4 ИИ
нужно около 24 ГБ свободной памяти: закройте тяжёлые программы или задайте `--instances`.

**Настройка** в `world.json`:
- версия сервера, сложность, seed;
- сколько ИИ (`"auto"` или число);
- для каждого ИИ: имя и **режим чувств**:
  - `grow` — глаза постепенно сменяют датчики, по мере того как учатся (как ребёнок);
  - `human` — только то, что есть у человека: зрение, слух, осязание, тело, HUD, книга рецептов;
  - `full` — датчики плюс глаза.

Разные режимы у разных ИИ — это готовый эксперимент: кто учится лучше.

**Панель** — http://127.0.0.1:8765, открывается сама:
- **«Кто лучше»:** таблица с сортировкой (достижения, предметы, технологии, смерти, средняя жизнь,
  исследованные чанки, понятия, точность зрения, итоговый счёт);
- **живые карточки:** что каждый видит прямо сейчас, что чувствует, чего хочет, что делает;
- **по выбранному ИИ:**
  - «Решения» — последние действия с целью и чувством;
  - «Жизнь» — достижения, первые предметы, смерти, слова, чему научились глаза;
  - «Зрение» — кадр с 25 зонами: что он узнал, уверенность, расстояние и ошибки;
  - «Сравнение» — графики всех ИИ по возрасту;
  - «Чувства и вещи», «Дневник».

**Как учить Синапса самому.** Зайдите своим клиентом Minecraft 1.21.4 на `localhost`.
- **Показывайте:** он видит, что вы ломаете (и чем), ставите, кого бьёте, что едите. То, чем вы
  пользуетесь, становится ему интересным, и повторить за вами ему приятно.
- **Объясняйте в чате:** «чтобы получить булыжник, нужна деревянная кирка», «факелы делают из угля
  и палок».
- **Просите:** «сделай деревянную кирку», «добудь дерево». Он ответит «Понял: …». Делать ли и когда,
  решает сам.
- **Тон:** «молодец», «осторожно», «нельзя» он чувствует как интонацию родителя.

**Гайд.** При первом запуске `world.py` скачивает Minecraft Wiki (около 2000 статей, 15–40 минут в фоне,
лицензия CC BY-NC-SA; хранится только на этом ПК, в `guide/`). Скачать отдельно: `python guide.py`.
Синапс читает гайд сам, когда хочет следующую ступень развития или не знает, как получить вещь. Что он
прочитал, видно на панели («Жизнь» → «гайд»).

**Самопроверка тела:** `python selftest.py` при запущенном мире. Заходит игрок «Tester», все
60 действий выполняются на площадке в небе и проверяются. Можно проверить только некоторые:
`python selftest.py sleep fish`. Итог пишется в `world/selftest.json`.

**Где хранятся данные.** Всё лежит в `minecraft/world/`: мир сервера и `life/<имя>/` каждого ИИ.
Ctrl+C — каждый мозг сохраняет выученное и засыпает. При следующем запуске жизнь продолжается.

## Тело в настоящем клиенте (мод Fabric, Minecraft 1.21.4)
Вместо бота Mineflayer телом может быть настоящий клиент игры с модом [`../fabric-mod`](../fabric-mod/README.md).
В нём видно окно игры с HUD Синапса, а глаза получают картинку из рендера самой игры. С
видеокартой картинка идёт в большую зрительную кору.

```bash
python setup_server.py --accept-eula --version 1.21.4   # серверу нужна та же версия
python run_synapse.py --body mod --eyes                 # клиент, Fabric, Baritone и мод ставятся сами
```

Протокол и номера действий те же, что у `bot.js`, так что мозг и память из `life/` общие для обоих тел.

## Чеклист разума (всё — выученные синапсы, не код навыков)
- **Видит и осязает:** зрение (`--eyes`) учится у прямых сенсоров прямо в игре (в логе: «eyes agree
  with the senses: front …%, sky …%»); `--eyes --blind` — действовать только по зрению. Сенсоры:
  блоки 5×5 впереди, осязание со всех сторон, над головой и под ногами, небо, «застрял».
- **Логические цепочки:** что обычно было у него перед тем, как что-то получилось, — становится
  предпосылкой («бревно ← вижу небо»).
- **Навыки:** как добиться каждого события — синапсы базальных ганглиев, обучение воспроизведением
  воспоминаний (в т.ч. «застрял → строить под собой / копать вверх»).
- **Рассуждение и самопознание:** обратный поиск от желаемого к тому, что можно сделать сейчас;
  нейроны компетентности («что у меня получается»); мысли вслух в чате и в дневнике.
Подробно и с замерами: раздел «Разум» в [`../README.md`](../README.md).

## Что он умеет технически (решает сам, когда)
40 действий: вперёд/назад/вбок, прыжок, бег, **Shift (присесть)**, повороты, взгляд вверх/вниз,
**удар (драка с мобами)**, использовать предмет, копать вперёд/вниз, **надеть лучшую броню**, взять
лучшее оружие, взять нужный инструмент, поставить блок, **смастерить новое**, **смастерить лучшее
снаряжение** (сам ставит верстак), **переплавить в печи**, поесть, **поставить кровать и лечь спать**,
выбросить мусор, **подняться, поставив блок под себя** (выбраться из ямы), **копать вверх**,
**рыбачить**, **взаимодействовать с существом** (покормить, приручить кота, правый клик по жителю —
открыть его товары), **торговать**, **положить в сундук / взять из сундука**, **поставить сундук**,
**читать книгу** (текст становится убеждениями в разуме), и **моторные программы**, которые наводит внимание
мозга: **подойти** к тому, что видит, **добыть** увиденный блок (подойти + нужный инструмент + копать),
**смастерить задуманное**, **дойти до запомненного места** (самого дорогого — дома), **уйти исследовать**
(прокладка пути — `mineflayer-pathfinder`, как мозжечок для ходьбы). Что именно — выбирает его разум
из своей цепочки: «хочу железо → нужно видеть железную руду → вижу её → добыть». Ни одно из них не привязано к ситуации: «увидел зомби —
бей» нигде не написано, бить или не бить — решает его мозг.

Знает все **729 рецептов** и **110 достижений** версии (`knowledge/`, собирается
`node build_knowledge.js 1.20.4 путь/к/server.jar`). Чувства: блоки 5×5 перед собой, направление на
ближайшее бревно, мобы (враги/животные: где и как далеко), здоровье, еда, броня, что в руке,
лучшая кирка, ночь, Shift/бег, достижения; по желанию — зрение (картинка от первого лица).

## Как он разговаривает
Вопрос сначала ищется в его эпизодической памяти (справочник рецептов и достижений + 88 тысяч
вопросов-ответов по вики) — если похожий вопрос найден уверенно, ответ точный. Иначе говорит
языковой мозг — свободно, но часто не по делу. Вопросы о себе («кто ты?») — из его автобиографии.
Рецепты он знает на английском.
